Usage

Click a key or knob to edit it. Scroll over a knob or use ↺ ↻ to simulate rotation; press the knob cap to simulate a click. Page-switch actions change the previewed page.

Page Settings

Needs the overlay running on the PC. Enter an app's program name (right-click the overlay to see the app you're in), or app:words to also match the window title, or :words to match any app's title. Separate several with commas.

Inspector

Global RGB · GP0

● device synced
Colour streams live while connected. Brightness, mode and statuses are written on Save.
Status lights

Turn a status on with a Status light action (or the IT Toolkit list). It overrides page colours and Off mode, and shows on the OLED, so people can see you're busy at a glance.

Deck Settings

Layout must match the PC so typed symbols like @ " # come out right. On slow or busy school PCs, raise Run box wait and Key delay if websites or apps open with missing characters.

Sleep & screen

While the screen is off (asleep or screen saver), the first press or turn only wakes it — nothing is sent to the PC. The screen saver drifts a small clock (or your status) around the OLED so it doesn't burn in. Quiet hours switch the pad off overnight; any key wakes it. Status lights keep showing unless the pad is asleep.

Auto Page Switching

Set rules per page in Page Settings. The overlay watches which app you're using and moves the pad to the matching page. It only switches when you change app, so turning a knob to another page by hand still works.

Pad Firmware

This editor carries the matching pad firmware. Update pad sends it over USB and restarts the pad (it needs firmware 2.2 or newer already on it, and USB drive mode off). Your old files are kept on the pad as main.bak.py and boot.bak.py.

Alerts & Integrations

Freshdesk
Wi-Fi & API key for alerts (stored on the deck only)

Saved in the deck's settings.toml — never in config.json, exports or this browser. Needs a normal password Wi-Fi (e.g. a staff IoT or guest network); networks that ask for a username (WPA2-Enterprise) won't work. The deck also needs the adafruit_requests and adafruit_connection_manager libraries in its lib folder.

Remote Desktop Manager

Tip: in RDM open an entry's Properties → Entry information → Create web Url → rdm://, then paste that link into an Open website key to open the session with one press.

School timetable
alertmin before, colour

Weekdays only. Uses the deck's clock, which is set automatically every time this editor connects (or over Wi-Fi).

Script alerts

Any script on the PC can flash the pad and put a message on the OLED — for example when a server or printer stops answering ping.
